# Changelog

## 0.1.0 — 2026-10-20

- All 23 operations in the supplied OpenAPI, sync and native asyncio clients.
- 111 named wire schemas plus inline models, typed requests, Decimal prices, cursor/offset iterators.
- Ed25519 signing over transmitted URL/body bytes, process-local shared limiter, conservative read retries.
- Partial batch results, deposit polling, unknown write outcomes and explicit withdrawal request IDs.
- Offline contract/transport tests, Python 3.14 type checks, CI and installable distributions.
- No live-account trading validation; P2P availability and upstream omissions are documented.
